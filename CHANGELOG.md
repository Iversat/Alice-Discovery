# Изменения

## 0.2.1

Я обновил название проекта на LS Discovery и оформление документации. Добавлена команда `ls-discovery`; прежняя команда и Python API сохранены.


## 0.2.0 — 20 октября 2026

- Документация описывает обнаружение сервисов mDNS.
- Обновления mDNS теперь применяются, исчезнувшие объявления корректно удаляются.
- Несколько сервисов на одном хосте больше не перезаписывают друг друга.
- Добавлены IPv6, безопасное представление бинарных TXT-свойств и копирование снимка под блокировкой.
- Отмена браузера и закрытие Zeroconf выполняются при завершении, ошибке и Ctrl+C.
- Добавлены аргументы CLI, вывод JSON, выбор интерфейса, установка пакета и CI.
- Сохранены `MyListener`, `scan_local_network_for_speakers` и исходное имя скрипта.

### Переход со старого API

`scan_local_network_for_speakers()` теперь возвращает список записей и не печатает их. Текстовый вывод формирует CLI. `MyListener.found_devices` возвращает копию словаря; ключом служит полное имя сервиса в нижнем регистре, а не имя хоста. Число записей обозначает число сервисов.

Минимальная версия Python повышена до 3.11.
