# Безопасность

Я прошу не публиковать полные сетевые дампы, имена, адреса и идентификаторы домашних устройств в открытых обсуждениях. Для отчёта об ошибке замените такие значения вымышленными, сохранив структуру записи.

LS Discovery получает объявления mDNS в выбранной локальной сети. Данные об устройствах не отправляются внешнему сервису; `--json` позволяет сохранить их в локальный файл. Сканируйте собственную сеть либо получите разрешение её владельца.

Об обычной ошибке напишите мне в [Issues](https://github.com/Iversat/LS-Discovery/issues). Если сообщение содержит чувствительные сведения, сначала свяжитесь со мной через контакты в [моём профиле](https://github.com/Iversat), не размещая эти сведения публично.
