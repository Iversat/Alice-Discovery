# Проверка LS Discovery

Я использую pytest для преобразования записей и обработки событий mDNS, Ruff — для проверки кода. GitHub Actions запускает проверки в Windows и Linux на Python 3.11, 3.12 и 3.14. Результаты доступны в [Actions](https://github.com/Iversat/LS-Discovery/actions).

## Автоматические проверки

```bash
python -m pip install -e ".[dev]"
python -m pytest --cov=multiroom_scanner --cov-report=term-missing
python -m ruff check .
python -m ruff format --check .
python -m pip check
python -m build
```

Тесты покрывают IPv4 и IPv6, бинарные TXT-поля, добавление, обновление и удаление сервисов, несколько объявлений одного хоста, снимки данных, входные параметры, JSON и освобождение ресурсов. Сетевое наблюдение подменяется: для обычного запуска тестов колонки не нужны.

## Проверка в сети

```bash
python multiroom_scanner.py --duration 5 --json
```

В собственной сети проверьте, что объявления содержат ожидаемые типы сервисов, адреса и TXT-свойства. После изменения или отключения устройства можно повторить сканирование и сравнить результат. Для выбранного интерфейса используйте `--interface`.

Я рассматриваю такой запуск как проверку обнаружения объявлений. Он не проверяет управление колонками или синхронное воспроизведение. Перед публикацией вывода заменяйте реальные сетевые данные вымышленными.
