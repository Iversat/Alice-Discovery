# Alice Discovery

Компактный Python-инструмент, который находит объявления умных колонок через mDNS и показывает их адреса, порты и TXT-свойства. Исходный файл `multiroom_scanner.py` сохранён.

**Python 3.11+** · **mDNS / DNS-SD** · **IPv4 + IPv6** · **JSON export**

[Быстрый старт](#быстрый-старт) · [Использование](#использование) · [Как это работает](#как-это-работает) · [Проверки](docs/TESTING.md) · [Правовое уведомление](LEGAL_NOTICE.md)

> Независимый исследовательский проект. Он обнаруживает опубликованные в локальной сети сервисы; функции мультирума и синхронного воспроизведения не реализованы. Проект не связан с Яндексом.

## Возможности

| Возможность | Что получает пользователь |
| --- | --- |
| Обнаружение mDNS | Сервисы Яндекс-колонок, Google Cast и Spotify Connect |
| Актуальные записи | Добавление, обновление и удаление объявлений |
| IPv4 и IPv6 | Адреса обоих семейств, включая scope для IPv6 при его наличии |
| TXT-свойства | UTF-8, флаги без значения и бинарные поля в виде `hex:…` |
| Выбор интерфейса | Сканирование через указанный локальный IP |
| JSON | Чистый stdout для перенаправления и обработки другими программами |

У одного устройства может быть несколько сервисов. Они сохраняются отдельно; количество записей — это количество объявлений сервисов, а не подтверждённое число физических устройств.

## Быстрый старт

```bash
git clone https://github.com/Iversat/Alice-Discovery.git
cd Alice-Discovery
python -m venv .venv
```

Активируйте окружение: `.venv\Scripts\Activate.ps1` в PowerShell или `source .venv/bin/activate` в Linux/macOS. Если активация PowerShell недоступна, используйте `.venv\Scripts\python.exe` вместо `python`.

```bash
python -m pip install -e .
python multiroom_scanner.py
```

После установки также доступна команда `alice-discovery`. Для воспроизведения проверенной версии зависимости можно установить `python -m pip install -r requirements.txt`.

## Использование

```bash
# По умолчанию — 10 секунд.
python multiroom_scanner.py

# Короткое сканирование.
python multiroom_scanner.py --duration 3

# Машинный вывод без служебных сообщений в stdout.
python multiroom_scanner.py --duration 5 --json > scan-results.json

# Только выбранный тип сервиса.
python multiroom_scanner.py --service _yandexio._tcp.local.

# Явно выбрать интерфейс по его локальному IP.
python multiroom_scanner.py --interface 192.0.2.20 --duration 5

python multiroom_scanner.py --help
```

`--service` и `--interface` можно повторять. `192.0.2.20` в примере — адрес из документационного диапазона; замените его адресом своего сетевого интерфейса. Длительность должна быть конечным числом больше нуля.

Пример вывода с вымышленным устройством:

```text
Найдено сервисов: 1

01  speaker-demo
    Сервис   _yandexio._tcp.local.
    Адреса   192.0.2.10, 2001:db8::1
    Порт     1961
    Имя      Demo._yandexio._tcp.local.
    TXT      {"platform": "demo", "cluster": "yes"}
```

## Как это работает

Скрипт подписывается на объявления mDNS/DNS-SD, получает сведения о сервисах и завершает наблюдение через заданное время. Он не подключается к объявленным портам, не отправляет команды воспроизведения и не обращается к аккаунту Яндекса.

Типы по умолчанию:

```text
_yandexio._tcp.local.
_yandexstation._tcp.local.
_googlecast._tcp.local.
_spotify-connect._tcp.local.
```

Python API возвращает список словарей и ничего не печатает:

```python
from multiroom_scanner import scan_local_network_for_speakers

records = scan_local_network_for_speakers(scan_duration_seconds=3)
for record in records:
    print(record["service_name"], record["addresses"])
```

Ключи записи: `name`, `server`, `service_name`, `type`, `addresses`, `port`, `properties`. Снимок защищён от изменений рабочего потока, а сетевые ресурсы закрываются также при ошибке и Ctrl+C.

## Если ничего не найдено

Проверьте, что компьютер и колонка находятся в одной локальной сети. Изоляция Wi-Fi-клиентов, гостевая сеть, VLAN, VPN или фильтрация UDP 5353 могут мешать mDNS. Попробуйте увеличить `--duration` и явно выбрать `--interface`; для диагностики есть `--verbose`.

Пустой список означает, что за время наблюдения выбранные объявления не обнаружены. Он не доказывает отсутствия устройств в сети. Свойства сервиса сообщаются самим устройством и не подтверждают его подлинность.
